# NeoForge 1.21.1 移植记录

## 目标与依赖

- Minecraft 1.21.1、NeoForge 21.1.228、Java 21、Gradle 8.14.3、ModDevGradle 2.0.141。
- SlashBlade Resharped 正式发布包 2.0.7-1.21.1（Modrinth 版本 ID：`u02EDgAr`）。
- 发布包 SHA-1：`d9ef461d1b2bc36cb2caeebe15be904f433e542c`。
- 模组 ID 为 `murasame`，当前未发布版本统一为 **2.0.0**，不提供旧版本存档或源码兼容层。

## 实现变化

- ForgeGradle 切换至 NeoForge ModDevGradle；替换加载元数据、事件、注册器和 Java 工具链。
- 刀数据改用 SlashBlade `BladeStateAccess`，觉醒标记改用 `CUSTOM_DATA`，附魔通过世界注册表取得 Holder。
- 嵌刀石通过已加载的命名刀定义创建刀，避免方块实体构造时访问尚未就绪的动态注册表。
- 创造栏由 SlashBlade 根据 `creativeGroup` 加入命名刀，公共初始化不再依赖 `Minecraft` 或客户端刀模型缓存。
- R 键改用有明确方向和版本的 NeoForge 自定义 payload；服务器按发送者更新刀灵状态。刀灵可见性与所属玩家继续使用实体同步数据。
- 玩家偏好改为可序列化、死亡后复制的 NeoForge 数据附件，替代未实现持久化的静态 UUID 映射与旧 Capability。
- 客户端按键、模型层和渲染器注册放入仅客户端加载的事件订阅类。刀灵同步数据定义改用 1.21.1 Builder API。
- 进度、结构资源迁移到 `advancement`、`structure` 单数目录，重新生成进度。命名刀仍使用上游自定义的 `slashblade/named_blades` 目录。
- 修复同一时间点的连段动作覆盖；延长连段存续时间以执行最后的恢复动作。空间斩保存的移动状态按施法者隔离，不再重置目标原有的无重力标志。
- 祝福按事件中的使用者与刀状态判定，暴击冷却按使用者保存，避免多人间串用血量、武器与冷却状态。
- 修复嵌刀石重复发放、经验变化同步、刀灵所属维度与跟随判断、客户端/服务器共享计时状态和缺失音效字幕。
- 觉醒阈值在检查时读取服务器配置，避免静态初始化过早读取或缓存过期配置。
- 嵌刀石参照 `murasame-1.1.4-fix.jar` 改为直接绘制丛雨丸 OBJ 的 `blade` 分组，沿用附件的 1.8 格高度、Z 轴 90° 旋转和 0.00635 缩放；不绘制刀鞘，空嵌刀石仍只显示石头。客户端测试已调用实际渲染器，并保存两种方块并排的游戏截图以检查方向与插入深度。

## 个人嵌刀石

世界中保留同一个方块，方块实体保存实例 UUID、原坐标/维度和已领取玩家 UUID。领取由服务端判定，先记账再发刀；重复交互不扣经验。区块发送完成后单独同步该玩家的状态，普通方块实体更新不包含其他玩家的领取列表。客户端只在状态已知且尚未领取时渲染武士刀，准星名称随个人状态变化。第三方方块提示模组暂未适配。

创造复制不写入实例 NBT；物品放置在复制 NBT 应用完成后重新初始化，覆盖原坐标放回的情况。结构 NBT 移至其他坐标或维度也创建新实例；正常原地加载保持记录。只注册一个嵌刀石方块并禁用掉落；空嵌刀石仅为玩家领取后的显示状态。

新增六项 GameTest 覆盖两人分别领取、重复交互、保存恢复、Ctrl 复制、带 NBT 的真实物品放置（新坐标及原坐标）、结构搬移、普通/精准采集掉落及破坏后拒绝领取。客户端检查同时验证同一种方块的两种个人显示、普通方块实体更新后仍保持已领取状态，以及保存退出后重登时通过区块同步恢复个人显示（CLIENT_STONE_REJOIN_PASSED）。

## 可配置破坏保护

新增服务端配置 `general.stoneUnbreakable`，默认为 `true`。嵌刀石动态读取配置，开启后挖掘进度为零，服务端破坏事件阻止生存模式破坏，但允许创造模式像破坏基岩一样移除，并提高爆炸抗性、禁止生物破坏和活塞移动。关闭时恢复石头原有行为；管理员命令和直接修改世界的工具仍可移除。

GameTest 已按生存不可破坏、创造可破坏的规则更新，使用真实玩家破坏入口和真实爆炸验证保护，并在同一现有方块上切换配置，验证生存/创造模式恢复可破坏。此前直接调用世界删除接口的测试仍验证删除后实例失效，不代表玩家能绕过保护。

## 创造栏合并

移除独立的 `murasame:murasame_tab` 注册，两把命名刀的 `creativeGroup` 改为 `slashblade:slashblade`，嵌刀石通过创造栏内容事件加入同一栏。独立空嵌刀石的注册和资源已移除。同步修正已有客户端检查的引用，本次按要求未运行测试；下方测试结果来自此前开发状态。
